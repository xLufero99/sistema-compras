## Descripción del sistema

El sistema consta de 3 servicios que se comunican entre sí:

- `cliente-api`
- `producto-api`
- `compra-api`

El servicio **`compra-api`** actúa como orquestador, comunicándose con los otros dos servicios para realizar las consultas de datos correspondientes.
